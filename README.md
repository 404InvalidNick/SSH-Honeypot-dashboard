# SSH Honeypot + Dashboard en Tiempo Real 🛡️

![Dashboard](https://via.placeholder.com/800x400.png?text=Mapa+de+Ataques+en+Vivo)

Honeypot SSH que **captura atacantes reales** y muestra sus intentos en un **dashboard interactivo con mapa mundial**.

## Características
- Captura: IPs, usuarios, contraseñas, comandos
- Geolocalización en tiempo real
- Dashboard en **Kibana**
- 100% Dockerizado
